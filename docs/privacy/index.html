本声明适用于 Chrome 和 Microsoft Edge 上的 Selector Clicker 扩展及本介绍网站。

处理哪些数据

当前标签页与页面元素
打开扩展弹窗时，扩展读取当前标签页的网址，从中取得主机名，用来查找该站点的规则。网页访问权限由你为当前站点授予。在已授权的网页内，扩展读取元素结构及部分属性来生成或匹配 CSS 选择器，并按规则需要检查页面路径、元素可见性和可用状态。
站点规则与设置
保存规则时，扩展记录该网站的主机名、CSS 选择器、规则标识、暂停状态，以及你设置的备注、生效路径和点击上限。扩展还保存自动点击开关和点击冷却时间。选择器可能包含用于定位元素的网页属性值。
点击统计
扩展在当前页面显示本页次数，并在浏览器本地保存每条规则的累计点击次数和上次点击时间，同时保存本机累计总数。

扩展只用这些数据来选取元素、执行和管理规则、显示统计。扩展不会保存完整浏览记录、网页正文、密码或表单输入值。

存储、同步与共享

规则、备注和设置保存在浏览器的扩展同步存储中。启用浏览器的扩展同步时，这些数据可由浏览器提供方（Chrome 的 Google 或 Edge 的 Microsoft）在你的同一浏览器账号下同步。点击统计和扩展记录的站点授权范围保存在当前浏览器的本地扩展存储中。

扩展无需注册 Selector Clicker 账号。开发者不运营接收这些数据的服务器，也不会接收、出售数据，或将其共享给广告商或分析服务。扩展不含广告或第三方分析代码。

如何管理和删除

  • 在扩展的「管理规则」页面可编辑或移除站点规则及备注。移除规则后，该规则过去的点击仍计入本机累计次数。
  • 可在浏览器的扩展详情中管理站点访问权限。在规则管理页可导出规则 JSON 文件，或点击复制按钮将规则 JSON 写入剪贴板。粘贴导入会在本机处理你填入输入框的内容。
  • 可在浏览器同步设置中关闭扩展同步。要删除已同步的规则，可在同步开启时先在扩展内移除它们。
  • 从浏览器卸载扩展会清除当前浏览器中扩展的本地存储，包括点击统计。其他设备或同步数据的保留由浏览器账号与同步设置管理。

网站托管

本网站由 GitHub Pages 托管，网页不设置 Cookie，也未加入访问分析脚本。GitHub 可能为安全目的记录访问者的 IP 地址。
