适用于 Chrome 和 Microsoft Edge

点选一次，
自动处理重复点击

在网页上直接选取按钮，按网站保存规则。下次同一网站上的弹窗或遮罩出现时，扩展会按你的规则自动点击。

查看安装与用法 GitHub 源码 ↗

按你设定的规则点击

◎

在页面上选取

鼠标悬停预览高亮，单击即可生成选择器。保存前可以确认匹配数量并填写备注。

⊞

规则按网站生效

按站点授权。所有规则均可集中管理，支持测试匹配、暂停、限制路径和导入导出。

↻

在页面变化时执行

启用后，页面元素变化会触发扫描。你也可以立即扫描，或调整同一元素两次点击之间的冷却时间。

≋

查看点击次数

在扩展弹窗查看本页和本机累计次数，在规则管理页查看每条规则的累计次数。

保存第一条规则

适合使用同一网站时反复遇到的弹窗关闭按钮和「稍后再说」提示。

查看完整安装说明 ↗
  1. 从 GitHub Releases 下载扩展 ZIP 并解压，在浏览器扩展管理页用「加载已解压的扩展程序」选择含有 manifest.json 的目录。
  2. 打开或刷新目标网页，在扩展弹窗授权当前站点并进入选取模式，然后在网页上单击目标。
  3. 核对适用网站和匹配数量，保存规则，再在扩展弹窗开启自动点击。
