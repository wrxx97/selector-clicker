# Selector Clicker

一个 Chrome / Microsoft Edge（Manifest V3）扩展：检测符合 CSS 选择器的页面元素，并在元素可见且未禁用时自动点击。它适用于广告关闭按钮、遮罩关闭按钮等重复性页面操作。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `auto-element-clicker`。

## 使用

1. 在目标网页打开扩展弹窗，点击“在页面上选取元素”。
2. 将鼠标移到要自动点击的按钮上，看到高亮后单击选取。按 Esc 退出选取。
3. 确认匹配数量和网站，再点击“保存规则”。同一网站的规则可以在扩展弹窗中查看或移除。
4. 打开弹窗右上角的开关，启用自动点击。

点选生成的规则只在当前主机名下生效。页面上有且仅有一个匹配元素时，扩展才会尝试点击它。

如果需要手填 CSS 选择器，展开“全局选择器（高级）”，每行填一个，然后点击“保存设置”。例如：

```css
.ad-close
[aria-label="Close ad"]
#popup .close
```

设置会在已加载扩展脚本的页面中生效。启用后会先扫描一次，之后在页面增删节点或元素属性变化时扫描。也可以在弹窗中点击“立即扫描”。同一个元素在冷却时间内最多点击一次，冷却结束本身不会触发扫描。

## 测试

需要 Node.js 18 或更高版本。进入扩展目录后运行：

```powershell
npm test
```

如果系统未安装 `npm`，可直接运行：

```powershell
node --test
```

测试不依赖浏览器或第三方包，覆盖以下行为：

- Manifest V3 的内容脚本、弹窗和 service worker 声明。
- 页面配置加载后点击可见的匹配元素。
- 页面增删节点或仅发生属性变化时触发扫描，短时间内的多次变化合并处理。
- 站点规则按主机名生效，并跳过有多个匹配项的规则。
- 不点击隐藏、禁用或已从页面移除的元素。
- 同一元素在冷却时间内不会重复点击。
- 无效选择器不会中断其余有效选择器的扫描。
- 从扩展设置停用后不再点击元素。

## 注意

- 手填的全局选择器会应用到所有普通网页，请使用足够具体的选择器，例如 `.advertisement .close`，避免误点页面中的正常按钮。
- 浏览器内部页面、扩展商店、PDF 查看器等受保护页面无法注入内容脚本。
- 点选支持普通网页的主文档。iframe 和 Shadow DOM 内部的元素无法直接点选。
- 只由 CSS 动画等样式变化导致的显示或隐藏，可能需要手动触发扫描。
